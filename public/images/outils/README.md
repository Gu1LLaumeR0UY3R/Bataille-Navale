# Aperçus des outils

Une image par outil, affichée dans l'arsenal (en bas de l'écran de jeu) et dans le médaillon qui suit le curseur
quand l'outil est en main. Tant qu'un fichier manque, le jeu affiche un pictogramme à la place : rien ne casse.

| Fichier        | Outil              |
| -------------- | ------------------ |
| `sonar.png`      | Sonar 3 × 3        |
| `brouilleur.png` | Brouilleur         |
| `bouee.png`      | Bouée leurre       |
| `drone.png`      | Drone de réparation |

Consignes :

- PNG (ou WebP renommé en `.png` si besoin) à **fond transparent**, carré, environ **512 × 512 px**.
- Rendu low poly dans le même style que `public/images/poisson.png`, objet centré avec une petite marge.
- Poids : moins de 150 Ko par image.
- Ajouter l'auteur et la licence dans `CREDITS.md` si l'image n'est pas de toi.
